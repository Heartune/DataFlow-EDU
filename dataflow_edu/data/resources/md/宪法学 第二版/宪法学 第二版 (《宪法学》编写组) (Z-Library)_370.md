# 后记

《宪法学》教材是马克思主义理论研究和建设工程重点教材。在编写过程中，得到了马克思主义理论研究和建设工程咨询委员会的指导，得到了中央有关部门和有关专家学者的帮助和支持。同时，广泛听取了高校宪法学课程教师和大学生的意见和建议。

本教材由首席专家许崇德、韩大元、李林主持编写。廉希圣、童之伟、胡锦光、莫纪宏、焦洪昌、刘茂林、林来梵、王磊、郑贤君、任进、傅思明等参加了本教材的撰写和修改工作。张磊主持了工程办公室组织的审改和统稿工作。何成、邵文辉、葛明珍、张翔、翟国强、李海青、宋凌云、田岩、冯静、宋义栋、张造群、武斌、王燕燕、汤荣光等参加了具体审改和统稿工作。参加集中阅读并提出修改意见的有：刘海年、朱景文、周叶中、齐小力、甘超英、王人博、李元起、刘永艳、齐延平、王洪祥、宋军、于文豪、潘迪、王亚敏等。
