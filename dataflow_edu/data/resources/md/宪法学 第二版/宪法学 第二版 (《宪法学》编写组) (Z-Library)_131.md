# 第二节 国家形式

国家作为统治阶级专政的工具，必须通过一定的形式表现出来。国家形式就是统治阶级实现国家权力的形式。任何阶级在掌握国家统治权之后必然建立一套国家权力运行机制，以保障和实现统治阶级的意志和利益。国家政权组织形式和国家结构形式是横向国家权力和纵向国家权力的具体体现。
