# 第二版后记

组织全面修订马克思主义理论研究和建设工程重点教材, 是推动习近平新时代中国特色社会主义思想和党的十九大精神进教材、进课堂、进头脑的重要举措。《宪法学》（第二版）是在第一版教材基础上修订而成的。在教材修订过程中, 得到了马克思主义理论研究和建设工程咨询委员会的指导, 得到了中央有关部门和有关专家学者的帮助和支持。同时, 也广泛听取了高校专业课程教师和学生的意见和建议。

教材修订课题组由胡云腾、胡锦光、李林任首席专家, 胡云腾主持修订, 焦洪昌、王磊、任进、江国华、刘茂林、翟国强、张震、王禹、谭红作为主要成员参加修订, 李军作为学术助手做了辅助性工作。何成主持了工程办公室组织的审改定稿工作。田岩、冯静、吴学锐、王昆、王勇、曹守亮、张文君、徐立恒等参加了审改。参加集中审阅并提出修改意见的有: 张文显、徐显明、朱景文、胡建淼、李树忠、郑贤君、秦前红、王敏远、湛中乐、张翔、姚国建、朱安东、黄宇菲等。
